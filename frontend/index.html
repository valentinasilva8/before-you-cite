What it checks

Notices in one dated Retraction Watch extract, then a live Crossref check when you name a DOI or a title. The extract is loaded when the process starts. A request does not download it.

Who it is for

Someone about to cite a paper, a journal, or a publisher, and the course grader who wants the tool log next to the answer.

How to use it

Paste the full citation as the model wrote it: title, authors, and link, not the link alone. A bibliography can hold up to 25 references. A journal or publisher name has to appear as it does in the extract. A topic alone gets a question back. A title with no DOI is compared with the Crossref hit and confirmed in this chat when it is not an exact match. No record is not a clean bill of health. It is a limit of this file.

Tool log

Each call names the agent that ran it. The result is the string the model saw.

Retraction Watch database via Crossref, CC0. Crossref REST calls use a polite mailto and do not store abstracts. Publisher strings are quoted as the file and as Crossref wrote them.
