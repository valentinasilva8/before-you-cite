What it checks

Two things: is this a real paper, and was it retracted or corrected? The date at the top right is the saved Retraction Watch file we search. We also look the paper up live in Crossref, the list most journals register papers in.

Who it is for

You got a reference from ChatGPT or another chatbot and you want to know if you can cite it.

How to use it

Paste what the chatbot wrote, including the link. Up to 25. A DOI is the paper's permanent ID. It looks like 10.1038/nature14539. A normal link works too. "No notice found" means we found no retraction. That is not proof the paper is sound.

This is how we read your paste. Change a field only if it is wrong, then run the check.

Only the first 25 references are included.
